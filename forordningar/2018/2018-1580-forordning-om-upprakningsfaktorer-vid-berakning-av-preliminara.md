# Förordning (2018:1580) om uppräkningsfaktorer vid beräkning av preliminära kommunalskattemedel för 2019

## 1 §

Följande uppräkningsfaktorer ska användas vid beräkning av preliminära kommunalskattemedel för 2019 enligt 4 § lagen (1965:269) med särskilda bestämmelser om kommuns och annan menighets utdebitering av skatt, m.m.

```
Inkomstår       Uppräkningsfaktor
2018            1,040
2019            1,039
```
